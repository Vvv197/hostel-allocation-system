Online Hostel Allocation System

A web-based hostel allocation and management system developed to simplify and automate the student hostel allocation process at Michael and Cecilia Ibru University (MCIU).

About the Project

The Online Hostel Allocation System was developed to reduce the challenges associated with manual hostel allocation, including overbooking, poor record management, allocation errors, and delays in processing student applications.

The system provides a centralized platform where students can submit accommodation applications and administrators can manage hostel allocation.

Technologies Used

* Frontend: React.js, HTML, CSS, JavaScript
* Backend: Node.js, Express.js
* Database: MongoDB
* Authentication: Express Sessions, bcrypt.js
* File Uploads: Multer

Key Features

* Student registration and login.
* Secure password handling.
* Student accommodation application.
* Payment evidence upload.
* Administrative approval of applications.
* Gender-based hostel allocation.
* Room capacity management.
* Hostel allocation status tracking.
* Administrative management of student records.

Project Structure

The project consists of a frontend application, backend server, database integration, and administrative functionality.

Installation and Setup

1. Clone the repository:
    git clone YOUR_REPOSITORY_URL
2. Navigate into the project directory:
    cd hostel-allocation-system
3. Install dependencies:
    npm install
4. Configure your environment variables.
5. Start the development server using the appropriate npm script.
